# Tapo Bulbs (TPAP)

A Home Assistant integration that adds support for Tapo smart bulbs using the newer TPAP encryption, which the built-in TP-Link integration reports as "Unsupported device".

## Supported devices

- Tapo smart bulbs (light entity: on/off, brightness, colour temperature, colour), e.g. L630

## Install

1. In HACS, add `https://github.com/leaha00/ha-tapo-trap-plugin` as a custom repository (type: Integration).
2. Download **Tapo Bulbs (TPAP)** and restart Home Assistant.
3. Go to Settings -> Devices & services -> Add integration -> **Tapo Bulbs (TPAP)**.
4. Enter the bulb's IP address and your TP-Link / Tapo account email and password.
